# 🚀 실전 MCP 연습 프로젝트 (Practice MCP)

이 저장소는 **Model Context Protocol (MCP)** 서버 및 클라이언트를 직접 구현하고 실험해보기 위한 실습 프로젝트입니다. 🌍 LLM(대형 언어 모델)이 내 컴퓨터의 로컬 환경이나 외부 API와 통신할 수 있도록 다양한 도구(Tool), 리소스(Resource), 프롬프트(Prompt)를 제공합니다.

---

## ✨ 프로젝트 주요 기능

### 🛠️ 제공하는 도구 (Tools)
외부 모델이 이 서버에 접속하면 아래의 4가지 기능을 사용할 수 있습니다:
- **`echo(message)`**: 전달받은 메시지를 그대로 반환하는 기본 테스트 도구입니다.
- **`get_weather(city)`**: 특정 도시의 실시간 날씨 정보를 조회합니다. (외부 공개 API인 `wttr.in` 연결)
- **`list_directory(path)`**: 내 컴퓨터(로컬 PC)의 특정 폴더 내 파일 목록을 조회하여 LLM에게 파일 시스템 접근 권한을 줍니다.
- **`calculate(a, b, operator)`**: 계산기 도구로 간단한 사칙연산을 수행합니다.

### 📦 리소스 다루기 (Resources)
- **`config://app/settings`**: 이 서버에서 가상으로 제공하는 앱 설정 JSON 데이터입니다. (다크모드 테마, 버전 정보 등 제공)

### 💬 프롬프트 템플릿 (Prompts)
- **`greet_user(name)`**: LLM에게 사용자 이름을 전달하면서, "친근하게 인사하고 위 계산기나 날씨 도구를 어떻게 쓸 수 있는지 안내해 줘"라고 지시하는 기본 프롬프트입니다.

---

## 📁 파일 구조 및 설명

- `server.py`: **FastMCP** 프레임워크를 사용하여 서버 측 도구, 리소스, 프롬프트를 정의하고 서버를 구동하는 핵심 파일입니다.
- `client.py`: 파이썬 코드로 서버 채널에 접근하여 응답을 주고받는 기본적인 터미널용 클라이언트 예제입니다.
- `web_client.py`: **Streamlit**을 활용하여 웹 브라우저에서 서버의 도구를 버튼으로 편하게 테스트해 볼 수 있는 직관적인 UI 기반 인스펙터입니다.
- `mcp.json`: (선택) 하드코딩 없이 외부 에디터(VS Code 등)나 Claude 데스크톱 앱에서 이 커스텀 서버를 손쉽게 등록해 활용할 수 있도록 돕는 설정 파일입니다.

## 🚀 설치 및 시작하기

### 1. 패키지와 가상환경 준비
빠르고 안전한 격리 환경을 위해 파이썬 가상환경 세팅을 추천합니다.
```bash
# 가상환경 생성
python -m venv .venv

# 가상환경 활성화 (Windows PowerShell 기준)
.venv\Scripts\Activate.ps1

# 필수 패키지 설치
pip install mcp streamlit httpx
```

### 2. 서버 및 클라이언트 실행 테스트
먼저 인스펙터나 클라이언트가 접속할 수 있도록 백그라운드에서 실행해야 할 서비스가 있는지 확인하세요. *(이 프로젝트는 클라이언트 스크립트 실행 시 내부적으로 서버 프로세스를 함께 구동하는 구조입니다.)*

**터미널에서 가볍게 테스트 (`client.py`)**
```bash
python client.py
```
> 도구 목록 및 날씨 조회, 계산기 사용 결과 등이 터미널에 텍스트로 바로 출력됩니다.

**웹 브라우저에서 편리하게 테스트 (`web_client.py`)**
```bash
streamlit run web_client.py
```
> 깔끔한 웹 인터페이스가 열리며, 제공되는 도구들을 클릭과 폼 입력으로 손쉽게 실험해 볼 수 있습니다.
